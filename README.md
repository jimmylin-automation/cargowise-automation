\# 🤖 CargoWise UI Automation (OpenCV + Python)



This project automates data entry in CargoWise using computer vision.



Instead of relying on API or system integration (not available in many enterprise tools),

this solution uses OpenCV to visually detect UI elements and interact with them.



Key capability:

\- Detect ETA input field dynamically

\- Perform automated data entry

\- Works without API access (legacy system compatible)
